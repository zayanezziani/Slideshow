How to Update Your Image Strips

Follow these steps to swap the scrolling strip images on your Squarespace page.

1

Edit the strips in Figma

Open the Figma file and locate the three strip designs (Strip 01, Strip 02, Strip 03). Make your changes directly in Figma.

Screenshot: Step 1 — Figma
2

Export as PNG

Select each strip frame, go to Export in the right panel, and export each one as PNG at 1x or 2x resolution.

Screenshot: Step 2 — Export Settings
3

Upload to Cloudinary

Log in to your Cloudinary account. For each strip, find the existing file, right-click it, and hit Replace. Upload the new PNG. The link stays the same — no code changes needed.

Screenshot: Step 3 — Cloudinary Replace
4

Copy the image URL

After uploading, right-click the asset and select Copy URL. Repeat for each of the three strips.

Screenshot: Step 4 — Copy URL
5

Update the code & paste into Squarespace

In the Figma file, go to the Code page. You'll see the embed code with three highlighted URL fields — one per strip. Paste each Cloudinary URL into the matching field. Then copy the entire code block and paste it into the Squarespace embed block, replacing the previous version.

Screenshot: Step 5 — Squarespace Embed
DO Always use Replace in Cloudinary so the URL stays the same.
DON'T Never delete and re-upload — this will change the URL and break the embed.
